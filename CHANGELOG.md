# Changelog

## 0.1.0rc1

Initial HoundCrawler preview, derived from the public Apache-2.0 HoundScraper core. Adds explicit sitemap/query/domain controls, per-job concurrency enforcement, bounded gzip sitemap discovery and paginated Firecrawl-subset results. Preserves separate HoundScraper APIs. See docs/verification.md for actual qualification and remaining limitations.
